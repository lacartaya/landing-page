Fecha: 30-10-2026. Ningún contrato ni transferencia se considera verificado solo por aparecer aquí.

| Servicio | Estado / datos / finalidad | Base prevista y revisión pendiente | Reducción aplicada |
|---|---|---|---|
| Cloudflare Pages / Functions | Previsto hosting/API; IP, metadatos y resumen enviado | Seguridad/interés legítimo y consulta precontractual; revisar entidad, DPA, subencargados, logs, ubicaciones y transferencias | Sin DB propia; errores sin datos; API no-store |

| Foto y logo aportados | Archivos locales | Confirmar derecho de uso comercial y autorías | Sin procesamiento externo del retrato |
| Analytics, Ads, Calendar, Maps, CRM, IA, monitorización de aplicación | No encontrados en código | Revisar nuevamente si se añaden; configuración de hosting no inspeccionada | No se instalaron |

No se afirma ausencia de transferencias fuera del EEE. Deben identificarse entidad contratante, destinos, garantías vigentes (adecuación o cláusulas y evaluación según corresponda), conservación y mecanismos de supresión por cuenta concreta. El contacto directo por email/WhatsApp también requiere estas decisiones aunque se mantenga el asistente desactivado.
